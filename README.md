# Student Profile Android App

## About the Project
Student Profile Android App is a simple Android application developed using Java and XML in Android Studio as part of the ApexPlanet Android Development Internship.

## Features
- Enter student full name.
- Enter college name.
- Enter course name.
- Validate that all fields are filled.
- Display the submitted profile details using a Toast message.

## Technologies Used
- Java
- XML
- Android Studio
- Gradle

## How to Run
1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Run the application on an Android emulator or device.

## Project Purpose
This project was created to practise Android application development, UI design, XML layouts, Java programming, and event handling.
